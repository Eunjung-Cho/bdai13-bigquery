# 개강 전 환경 준비

첫 수업에서 SQL과 데이터에 집중할 수 있도록 로그인, 프로젝트, 조회 권한을 미리 확인합니다. 준비에 약 30–45분을 잡으세요. **학생 개인 결제 등록은 수업의 전제 조건이 아닙니다.**

## 1. 준비물과 프로젝트의 역할

| 준비물 | 사용하는 이유 | 완료 기준 |
| --- | --- | --- |
| Google 계정 | BigQuery·대시보드 로그인 | Chrome에서 로그인 가능 |
| 생성형 AI 도구 1개 | SQL 초안 작성과 검증 연습 | 텍스트 질문 가능 |
| 개인 GCP 프로젝트 | SQL 실행과 개인 결과물 저장 | BigQuery 쿼리 편집기 열림 |
| 공유 데이터 접근 권한 | 강사가 준비한 세 테이블 조회 | 스키마와 미리보기 확인 |

GCP 프로젝트는 작업의 관리 단위, 데이터셋은 테이블을 묶는 공간, 테이블은 행과 열로 된 데이터입니다. SQL의 테이블 주소는 다음과 같습니다.

```text
프로젝트.데이터셋.테이블
finda-13-2026.tabformer.transactions   ← 강사가 읽기를 허용한 원천
YOUR_PROJECT.bdai13                     ← 개인 뷰와 마트를 저장할 공간
```

**데이터가 있는 프로젝트와 쿼리를 실행하는 프로젝트는 다를 수 있습니다.** 쿼리 사용량은 실행 프로젝트에 연결됩니다. 테이블을 다른 프로젝트에서 읽는다고 그 원본 소유자가 학생의 실행 비용을 자동으로 부담하지 않습니다.

## 2. BigQuery 샌드박스로 시작하기

1. [Google Cloud Console](https://console.cloud.google.com/bigquery)에 로그인합니다.
2. 본인 프로젝트를 만들거나 실습용 프로젝트를 선택합니다. 표시 이름과 프로젝트 ID는 다릅니다. SQL에는 **프로젝트 ID**를 씁니다.
3. BigQuery 화면으로 이동해 샌드박스 안내를 확인합니다. 기존 유료 프로젝트를 선택했다면 샌드박스와 비용 조건이 다릅니다.
4. 쿼리 편집기를 열고 다음 문장을 실행합니다.

```sql
SELECT
    'BDAI 13기' AS course,
    2 + 3 AS first_result;
```

기대 결과는 `BDAI 13기`, `5` 한 행입니다. 이 쿼리는 강의 원천 테이블에 접근하지 않으므로 계정과 편집기 준비를 독립적으로 확인할 수 있습니다.

!!! note "샌드박스의 범위"
    공식 문서 기준 무료 사용 범위는 월 1TiB 쿼리 처리와 10GiB 활성 저장입니다. 샌드박스 테이블·뷰·파티션에는 60일 만료가 적용되고, 스트리밍과 DML 등 일부 기능은 제한됩니다. 이 수업은 주로 SELECT와 5주차의 CREATE VIEW·CREATE TABLE AS를 사용합니다. 과금 계정 연결 여부에 따라 한도와 동작이 달라질 수 있으므로 개강 전 [현재 샌드박스 조건](https://docs.cloud.google.com/bigquery/docs/sandbox)을 확인하세요.

## 3. 공유 데이터에 연결하기

강사가 공지할 정보는 다음 네 가지입니다. 임의의 값으로 추측하지 마세요.

| 필요한 정보 | 자료 안의 표시 | 확인 방법 |
| --- | --- | --- |
| 원천 프로젝트 ID | `finda-13-2026` | 강사 공지 |
| 원천 데이터셋 ID | `tabformer` | Explorer에서 확인 |
| 데이터 위치 | 강사 공지값 | 데이터셋 상세 정보 |
| 학생에게 부여된 읽기 권한 | 데이터 조회 가능 여부 | 테이블 스키마·미리보기 |

Explorer에서 프로젝트를 추가하고 `transactions`, `users`, `cards`를 찾습니다. 테이블 **스키마**와 **미리보기**를 먼저 확인하세요. 원본을 복사 적재할 필요는 없습니다. 컬럼명은 [데이터 가이드](data-guide.md)의 계약과 비교합니다.

```sql
-- finda-13-2026를 강사가 공지한 프로젝트 ID로 바꿉니다.
SELECT table_name, column_name, data_type, is_nullable
FROM `finda-13-2026.tabformer.INFORMATION_SCHEMA.COLUMNS`
WHERE table_name IN ('transactions', 'users', 'cards')
ORDER BY table_name, ordinal_position;
```

오류가 나면 오류 메시지와 **실행 프로젝트/데이터 위치/테이블 주소**를 기록해 질문하세요. 로그인 이메일이나 식별자 목록을 공개 저장소에 올리지 않습니다.

## 4. 비용 안전장치 익히기

쿼리를 실행하기 전 처리 예상량을 보고 [비용 기록표](templates/cost-log.md)에 적습니다. 예상 처리량과 실제 처리량은 다를 수 있습니다. 특히 클러스터링 테이블의 실행 전 추정은 상한값일 수 있습니다.

| 장치 | 하는 일 | 하지 않는 일 |
| --- | --- | --- |
| 테이블 미리보기 | 일부 행을 살펴봄 | SQL 집계 검증을 대신함 |
| 쿼리 검사·dry run | 문법과 예상 처리 바이트 확인 | 비즈니스 지표가 옳은지 판단 |
| Maximum bytes billed | 설정한 상한을 넘는 쿼리 실행 제한 | 저장비·다른 서비스 비용 전체 제한 |
| 예산 알림 | 설정 기준에 맞춰 알림 | 결제·쿼리를 자동 중단 |

쿼리 설정에서 **최대 청구 바이트**를 확인하세요. 숫자는 바이트 단위입니다. 첫 탐색 때는 교사가 안내한 상한을 사용하며, 예상량보다 작아 실행이 거절되면 쿼리 범위를 먼저 살핍니다. 상한을 무조건 높이는 것이 오류 해결 방법은 아닙니다.

`LIMIT 100`은 결과 행을 줄이는 문법입니다. 일반적인 비클러스터 테이블에서 읽는 컬럼의 전체 스캔을 줄여 주지는 않습니다. 필요한 컬럼 선택, 실제 파티션 열의 기간 조건, 작은 집계 마트가 각각 무엇을 줄이는지 구분합니다.

## 5. 5주차 저장 공간 준비

5주차 전에 개인 프로젝트에 `bdai13` 데이터셋을 만듭니다. 데이터 위치는 원천 데이터셋과 같게 설정합니다. 다른 리전에 있는 데이터를 한 쿼리로 조인하거나 잘못된 위치에 결과물을 만들면 실패할 수 있습니다.

CREATE 문장은 테이블을 쓰는 작업입니다. 본인 데이터셋의 작성 권한이 있어야 합니다. 예제의 목적지 `YOUR_PROJECT`를 바꾸기 전에는 실행하지 않습니다. 샌드박스 만료 때문에 포트폴리오를 오래 유지하려면 SQL을 따로 보관하고 집계 결과도 내보내 두세요.

## 6. Streamlit 직접 연결 준비

6주차는 Streamlit으로 앱을 만듭니다. BigQuery Python 클라이언트는 결제 계정 없는 샌드박스 사용도 지원합니다. 개인 무료 실행 프로젝트와 자신의 집계 마트를 사용하고, 공개 앱의 서비스 계정·조회 권한·Secrets를 5주차 과제 기간에 준비합니다.

기본 경로는 **BigQuery 집계 마트 → Python 조회 → Streamlit Community Cloud**입니다. 서비스 계정 사용이 어려우면 **Colab 본인 로그인 → 집계 결과를 DuckDB 파일로 저장 → 같은 Streamlit 앱**의 예비 경로를 사용합니다. 이 경로는 스냅샷이고 CSV로 변환하지 않습니다.

상세 단계와 기본 앱은 [Streamlit과 데이터 연결](reference/dashboard-connection.md)에 있습니다. GCP 인증 설정은 제공 안내를 따라가고 Python 전체를 새로 학습할 필요는 없습니다. 앱은 원천 2,400만 건을 전부 읽지 않고 작은 집계 마트만 읽습니다.

## 자주 막히는 지점

| 증상 | 먼저 확인할 것 |
| --- | --- |
| 프로젝트가 안 보임 | 로그인 계정, 프로젝트 ID, Explorer 추가 여부 |
| Access Denied | 원천 읽기 권한과 실행 프로젝트의 작업 권한을 따로 확인 |
| Not found in location | 데이터셋의 위치와 쿼리 실행 위치 |
| 컬럼을 찾을 수 없음 | 실제 Schema와 자료의 컬럼명 차이 |
| Maximum bytes 초과 | SELECT 컬럼·기간·필터와 상한값 |
| 테이블이 사라짐 | 샌드박스 만료와 저장한 CREATE SQL |
| 앱의 BigQuery 접속 실패 | 실행 프로젝트·리전·서비스 계정 조회 권한·Secrets |
