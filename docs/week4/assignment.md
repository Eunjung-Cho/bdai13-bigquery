# 4주차 과제. 변화가 나타난 곳을 증거로 설명하기

[강의](lecture.md) · [실습](lab.md) · [프로젝트](../project.md)

예상 소요 시간은 90–120분입니다. 필수 비즈니스 질문 2개와 선택 질문 1개로 구성합니다. 이번 주부터 개인 프로젝트의 질문과 검증 기록을 함께 축적합니다. 팀 리뷰/발표 및 제출 채널의 세부 사항은 강사 공지를 따릅니다.

수업의 완성 SQL을 수정해 제출해도 됩니다. 질문 1은 월별 결과에서 온라인만 고른 뒤 두 달을 비교하고, 질문 2는 90을 180으로 바꾸는 단계부터 시작하세요. 먼저 기본 결과를 확인하고 추가 문법은 필요할 때 붙입니다.

## 질문 1. 온라인 순거래액 변화가 큰 달은 어느 업종에서 달라졌는가? — 45분

2018년 온라인 채널의 월별 순거래액을 구하고, 2–12월 중 전월 대비 **절대 증감액이 가장 큰 달** 하나를 고릅니다. 그달과 전월의 MCC별 순거래액 차이를 구하여 변화가 큰 업종을 설명하세요.

**반드시 먼저 정의할 것**

- 온라인은 `use_chip = 'Online Transaction'`입니다.
- 날짜/금액 정제와 교육용 승인 조건, 환불 포함은 수업과 같습니다.
- “가장 큰 변화”는 `ABS(이번달 - 전월)`이며, 동률이면 더 이른 월을 고릅니다.
- 월 달력을 만들어 12개월을 유지합니다. 첫 달과 0 분모 변화율은 NULL입니다.
- 두 비교 월 중 한쪽에만 존재하는 MCC도 포함하고 반대편 금액을 0으로 둡니다. 원천 수집 누락을 0으로 치환하지 않습니다.

**제출할 표**

(1) 온라인 12개월의 순거래액, 전월 금액, 증감액, 증감률.

(2) 선택 월과 전월의 MCC별 금액 및 증감액. MCC별 증감액 총합이 온라인 전체 증감액과 일치하는지 확인합니다.

**힌트:** 먼저 실습의 36행 결과에서 온라인만 선택합니다. 비교할 두 월을 확정한 후, 그 두 월의 MCC 합집합을 기준으로 조건부 집계 `SUM(CASE WHEN ... THEN amount_usd ELSE 0 END)`를 쓰면 한쪽 월에만 있는 업종도 남길 수 있습니다. 변경 폭 상위 몇 개만 해석하더라도 합계 검증은 전체 MCC로 합니다.

**해석 문장:** “선택 월의 온라인 순거래액은 전월보다 ○○만큼 변했고, MCC A와 B에서 큰 증감이 관측되었다. 다만 ○○ 원인은 현재 표로 확인할 수 없다.” 빈칸에는 실행한 실제 결과만 넣습니다.

## 질문 2. 휴면 기준을 바꾸면 관찰 대상은 얼마나 달라지는가? — 30분

기준일을 2019-01-01로 유지하고, 기준일 이전 전체 유효 거래 이력으로 90일 이상 미거래 후보와 180일 이상 미거래 후보의 고객 수를 비교하세요. 관측 이력 없음은 별도로 세고 어느 후보 집합에도 자동 포함하지 않습니다.

**검증할 관계**

- 180일 이상 후보는 90일 이상 후보의 부분집합이므로 고객 수가 더 클 수 없습니다.
- 각 기준에서 “관측 이력 없음 + 기준 미만 + 기준 이상”은 users 스냅샷 고객 수와 같아야 합니다.
- 기준일 이후 거래가 마지막 거래일 계산에 들어가면 안 됩니다.
- 89, 90, 179, 180일 가상 경계를 직접 만들어 분류를 확인합니다.

**해석 질문:** 더 엄격한 기준이 왜 무조건 더 좋은 정의는 아닐까요? 캠페인 목적, 정상 거래 주기, 관측 기간 한계를 구분하여 3–5문장으로 답합니다. 실제 마케팅 실행이나 개별 연락은 과제 범위에 없습니다.

## 질문 3. Top 5에서 동률을 모두 살리면? — 선택 15분

실습 1의 ROW_NUMBER를 동률 포함 순위로 바꿔 봅니다. 정확히 5개 선정과 공동 순위 포함이라는 두 정책을 비교하고, 동률이 없는 실제 결과라면 작은 교육용 가상 데이터로 차이를 보여 줍니다. 실제 데이터에 동률이 있었다고 지어내지 않습니다.

## AI 요약 검증과 프로젝트 메모 — 15분

AI에 질문 1의 집계표를 주고 요약을 요청합니다. 실제 생성 문장 3개에 대해 “표의 어느 셀로 확인했는가”를 적습니다. 수치가 맞더라도 원인 단정이나 모집단 일반화가 있으면 수정합니다. AI가 만든 SQL을 사용했다면 생성 구간과 수정 구간도 표시합니다.

프로젝트 질문은 이번 과제를 발전시키거나 새 질문을 선택할 수 있습니다. 다음 다섯 항목을 한 페이지에 정리하세요.

| 항목 | 작성 내용 |
| --- | --- |
| 질문 | 누가 무엇을 판단하기 위해 어떤 비교가 필요한가 |
| 범위 | 기간과 세그먼트, 제외 조건 |
| 지표 | 분자/분모, 환불과 NULL 처리 |
| 검증 | 총합 일치, 조인 보존, 날짜 경계 중 필요한 것 |
| 한계 | 현재 데이터로 말할 수 없는 것 |
